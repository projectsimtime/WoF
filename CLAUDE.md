# WoF Project Instructions

Read and follow `AGENTS.md` in this directory as the authoritative working agreement for this project.

The essential constraints are:

- The primary goal is passing the Vertigo Games revision test within two days.
- Directly address the supplied feedback; do not build speculative architecture.
- Preserve existing gameplay behavior during refactors.
- Do not add patterns, interfaces, base classes, installers, or extra layers merely to demonstrate SOLID.
- Match the user's existing coding and naming style.
- Explain material architecture or behavior changes in Turkish and get explicit approval before editing.
- Do not write code when the user asks to discuss or learn.
- Do not touch `TASKS.md`, `NOTES.md`, or unrelated changes without explicit permission.
